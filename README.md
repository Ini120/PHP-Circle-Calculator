# PHP Circle Calculator

A simple and responsive circle calculator built with PHP, HTML, and CSS.

This project was created as a practical exercise while learning PHP and server-side form handling. The user enters a radius, and the application calculates the circumference, area, and volume of a sphere.

## Features

- Accepts a radius from the user
- Calculates circumference
- Calculates circle area
- Calculates sphere volume
- Displays results to two decimal places
- Uses the HTTP POST method to process form data
- Responsive design for different screen sizes
- Clean and simple user interface

## Technologies Used

- HTML5
- CSS3
- PHP

## Formulas Used

### Circumference
C = 2πr

### Area
A = πr²

### Volume of a Sphere
V = 4/3πr³

How to Run

Since this project uses PHP, you need a local PHP environment such as XAMPP.

Clone the repository:
-git clone https://github.com/Ini120/php-circle-calculator.git
-Move the project into your XAMPP htdocs folder.
-Start Apache from XAMPP.
-Open the project in your browser:
-http://localhost/php-circle-calculator/
